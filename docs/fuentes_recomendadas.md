# Fuentes recomendadas

Las siguientes fuentes y plataformas pueden proporcionar recursos académicos confiables:

1. **Google Scholar**: Buscador de artículos, tesis, libros y publicaciones académicas.
2. **SciELO**: Biblioteca electrónica con artículos científicos y académicos.
3. **Redalyc**: Plataforma que ofrece revistas científicas y publicaciones académicas de acceso abierto.
4. **Dialnet**: Base de datos especializada en artículos, libros y documentos académicos.
5. **Microsoft Academic / OpenAlex**: Recursos para localizar publicaciones y trabajos de investigación.
6. **Biblioteca Digital Mundial**: Permite consultar diferentes recursos educativos y documentos históricos.
