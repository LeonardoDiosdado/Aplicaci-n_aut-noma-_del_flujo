# Criterios para clasificar recursos

## Criterios adicionales

### 1. Actualización
Se debe considerar la fecha de publicación o actualización del recurso. Se recomienda utilizar información reciente cuando el tema requiera datos actuales.

### 2. Relevancia
El recurso debe estar relacionado directamente con el tema de investigación y aportar información útil para cumplir con el objetivo académico.
