Aplicación autónoma del flujo de trabajo

Aplicar de manera autónoma el flujo de preparación, versionamiento y colaboración de un proyecto
utilizando Visual Studio Code, Python, Git y GitHub. En esta práctica no se proporcionan los comandos: cada
instrucción describe una acción y el resultado esperado, y deberás determinar qué comando utilizar,
ejecutarlo y comprobar su resultado.

• El código y la estructura completa del proyecto.
• El archivo docs/respuestas.md con todas las respuestas solicitadas durante la práctica.
• La carpeta docs/evidencias/ con las imágenes que demuestren el desarrollo del flujo.
• El historial de commits, ramas utilizadas, Pull Requests y cambios integrados en main.git
